## DESCRIÇÃO
Aplicação Full-Stack para gerenciamento e listagem de produtos com autenticação baseada em tokens JWT.

-Tecnologias Utilizadas:
Backend;
Linguagem: Java(v25)
Framework: Spring Boot (v3.x / v7.x modules)
Segurança: Spring Security + Auth0 Java JWT

Frontend;
Framework: Next.js
Linguagem: TypeScript

Este projeto foi desenvolvido como projeto prático e consolidador durante o curso de API REST com Spring Boot da Formação DEV.
 
 ##Instrução de uso
 1. Abra localhost:3000
 2. Faça cadastro
 3. Adicione produtos
